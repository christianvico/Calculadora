# Calculadora Java + HTML

Aplicacion web con interfaz en HTML y servidor HTTP nativo en Java para resolver operaciones matematicas basicas (`suma`, `resta`, `multiplicacion`, `potencias` y `division`) con numeros enteros de 5 digitos (`-99999` a `99999`).
